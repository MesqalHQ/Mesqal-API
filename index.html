Overview

This is the public data API for the Mesqal ecosystem. It provides live and historical prices for gold, currencies, cryptocurrencies, and PAMP bars in the Iranian market, updated every 30 minutes via GitHub Actions.

Endpoints

GET /data/dates.json
Returns an array of all available dates (YYYY-MM-DD), sorted newest first. 
[
  "2026-09-20",
  "2026-09-19",
  "2026-09-18",
  ...
]
GET /data/{date}.json
Returns all price snapshots for a specific date. Each entry contains timestamp, financial data, and PAMP bar prices. 
[
  {
    "time": "14:30:00",
    "financial": [
      { "key": "usd", "price": 62500 },
      { "key": "sekkeh", "price": 42500000 },
      { "key": "usd_btc", "price": 65000 }
    ],
    "pamp": {
      "items": [
        { "weightGram": 1, "price": 4500000 }
      ]
    }
  }
]

Usage Example

// Fetch latest available date
const res = await fetch("https://mesqalhq.github.io/Mesqal-API/data/dates.json");
const dates = await res.json();
const latest = dates[0]; // "2026-09-20"

// Fetch today's data
const data = await fetch(`https://mesqalhq.github.io/Mesqal-API/data/${latest}.json`);
const snapshots = await data.json();
